# Bayesian Sample Size Determination in Multivariate Cluster Randomised Trials
Research compendium of the project *Bayesian Sample Size Determination in Multivariate Cluster Randomised Trials*. The aim of this project is to develop a method and tools for sample size determination of multivariate cluster randomised trials when using the Bayes factor for hypothesis testing. Further details about the project can be found in the OSF project
